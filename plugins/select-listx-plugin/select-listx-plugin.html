📋 Select ListX Plugin 📋

Import in Perchance code panel:

selectListX = \{import:select-listx-plugin\}

This plugin provides a comprehensive, hierarchical, and extensible set of lists for character generation, covering identity, appearance, personality, background, skills, relationships, and more.

  • All standard and extended character attributes
  • Supports leaf selection, random sampling, and unique draws

Example usage:

Combine different single lists: 

[character.identity.name.first.male.selectOne] [character.identity.name.last.common.selectOne]

Select many from the same list in this example 3 names: 

[character.identity.name.first.male.selectMany(3).joinItems(", ")]

Select all from the same list: 

[character.joinItems(", ")]

Name: [character.identity.name.first] [character.identity.name.last.common]
Age: [character.identity.age]
Gender: [character.identity.gender]
Species: [character.identity.species]
Pronouns: [character.identity.pronouns]
Species: [character.identity.species.selectOne]

Sections included:

  • Identity (name, age, gender, species, sexuality, pronouns, etc.)
  • Appearance (skin, eyes, hair, height, build, genitals, modifications, etc.)
  • Personality (traits, quirks, alignment, values, etc.)
  • Background (origin, culture, occupation, education, wealth, etc.)
  • Skills & Abilities (combat, magic, talents, languages, etc.)
  • Relationships (family, friends, rivals, romance, etc.)
  • Equipment (clothing, weapons, items, etc.)
  • Portrait (style, pose, clothing, accessories, lighting, etc.)
