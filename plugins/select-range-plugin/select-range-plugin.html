Select Range Plugin

Put this in your Perchance code panel:

selectRange = \{import:select-range-plugin\}

Now you select specific ranges of items from your list:

  • 3rd to 7th item: \[selectRange(animal, 3, 7)\]
  • 12th to 30th item: \[selectRange(animal, 12, 30)\]
  • 4th item onwards: \[selectRange(animal, 4)\]
  • 26th item onwards: \[selectRange(animal, 26)\]

So the notation is \[selectRange(list, start, end)\].

If you omit end, it'll assume you want all the rest of the items.

Both numbers in the range are inclusive (start and end items are included).

You can also reference items counting from the end of the list using the minus sign:

  • last 5 items: \[selectRange(animal, -5)\]
  • only the last item: \[selectRange(animal, -1)\]
  • last 3 items: \[selectRange(animal, -3)\]
  • 2nd item up to the 4th last item: \[selectRange(animal, 2, -4)\]
  • 5th last item up to the 3th last item: \[selectRange(animal, -5, -3)\]
  • all items except the last one: \[selectRange(animal, 1, -2)\]
  • all items except the last 3: \[selectRange(animal, 1, -4)\]

You can use the "sublist" like it's a normal list:

  • \[sublist = selectRange(animal, 3, 8), ""\] and then later:
  • \[sublist.pluralForm\], or:
  • \[sublist.joinItems(",")\], or:
  • \[selectRange(sublist, 3, 5)\]
  • etc.
