Seeder Plugin 🌱

This plugin allows you to create seeded randomness - so you can give your generator a string, and it'll generate the same "random" sequence of selections if you enter that string later. Just put this code in your perchance code panel:

seeder = \{import:seeder-plugin\}

And then put this in your HTML panel:

<input placeholder="Enter a seed..." oninput="seeder(this.value), update()">

So now when you type some letters and numbers into that input form, the seed will be updated and all the following "randomize" clicks will produce a sequence that is specific to that particular seed. So you could send the seed to your friend and they would paste it in and each time they clicked the "randomize" button they'd see exactly the same sequence of random results that you saw.

Want to embed the seed in the URL, so you can share your generator with a link that has a default seed embedded? Import the url-params-plugin like this:

url = \{import:url-params-plugin\}

and then write \[seeder(url.seed)\] at the top of your HTML (bottom-right) editor panel.

And now you can share your generator with a seed like this:

https://perchance.org/your-generator-name?seed=yourseedtext

...and the page will load with a default seed of yourseedtext. Here's a working example. And here's an example that has a live-updating link to the seed as you change it.
