Quota Budget Kit

Rate-limit expensive features with scoped budgets, sliding windows, and action-level consumption controls.

quota = \{import:quota-budget-kit\}

Budget Setup

create, setLimit, remove, list

Usage Control

consume, grant, reset, cleanup, status

Windows

Automatic window refresh keeps limits predictable over time.

Portability

exportJson and importJson support policy migration.

Example Pattern

quota = \{import:quota-budget-kit\}

\[quota.create("ai", "imageGen", 10, 60000, 0)\]
First = \[quota.consume("ai", "imageGen", 1)\]
Now = \[quota.status("ai", "imageGen")\]

CanProceed = \[Now.remaining > 0\]
