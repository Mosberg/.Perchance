css-style-plugin

Universal all-purpose stylesheet for Perchance generators.

Usage: Add cssStyle = {import:css-style-plugin} to your main.pjs, then call cssStyle() in a script tag at the top of your index.html. Wrap your content in a <div data-csp> element.
