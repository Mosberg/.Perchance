Schema Guard Kit

Data validation and sanitation for stable contracts between UI, AI, and runtime systems.

schema = \{import:schema-guard-kit\}

Validation

validate, requireFields, typeErrors, assert

Transforms

sanitize and mergeDefaults keep incoming data predictable.

Contracts

Use type specs to avoid hidden failures in large projects.

Reporting

reportJson makes inspection and logging straightforward.

Example Pattern

schema = \{import:schema-guard-kit\}

InputData = \{"name":"Rae","level":4,"tags":["mage"]\}
Required = \["name", "level"\]
Types = \{"name":"string", "level":["integer", "number"], "tags":"array"\}

Report = \[schema.validate(InputData, Required, Types)\]
SafeData = \[schema.sanitize(InputData, \["name", "level", "tags"\], "trim")\]
Merged = \[schema.mergeDefaults(SafeData, \{"level":1, "tags":\[\]\})\]
