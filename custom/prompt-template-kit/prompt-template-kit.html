Prompt Template Kit

Prompt Template Kit

Store and render reusable templates with scoped registries, token extraction, and batch composition.

prompts = \{import:prompt-template-kit\}

Template Store

set, get, has, remove, list, clear

Rendering

renderText, render, renderBatch with configurable missing-token behavior.

Token Tools

tokenList and preview speed up debugging and editor tooling.

Import/Export

exportJson and importJson support reusable packs across projects.

Example Pattern

prompts = \{import:prompt-template-kit\}

\[prompts.set("npc", "intro", "Name: \{\{name\}\} | Role: \{\{role\}\}")\]
Text = \[prompts.render("npc", "intro", \{"name":"Kara","role":"Scout"\}, "missing")\]
Tokens = \[prompts.tokenList(\[prompts.get("npc", "intro")\], ", ")\]
