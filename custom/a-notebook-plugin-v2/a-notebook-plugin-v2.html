A Notebook Plugin v2

Notebook Plugin v2 is a larger, configurable notebook system for Perchance generators. It includes page tags, search, sorting, archive/pin workflows, keyboard shortcuts, configurable storage, shared profile persistence (username/password), import/export, and a richer API.

1. Import in Code Panel

notebookV2 = \{import:a-notebook-plugin-v2\}

2. Mount in HTML Panel

\[notebookV2.mount()\]

This mounts a floating button and modal interface. Use one mount call per page.

3. Optional Configuration

\[notebookV2.mount(null, \{
  title: "Writer Notebook",
  buttonLabel: "Open Notes",
  buttonPosition: "bottom-left",
  storageKey: "my_generator_notes_v2",
  storageDriver: "auto", // auto | localStorage | kv
  enableProfile: true,
  profileStorageKey: "__a_notebook_plugin_shared_profile_v1",
  autosave: true,
  autosaveDelay: 400,
  maxPages: 800,
  defaultSort: "updated_desc",
  showArchived: false,
  keyboardShortcuts: true,
  importMergeStrategy: "prepend"
\})\]

4. Core Features

  • Page create, rename, duplicate, delete
  • Pin and archive states per page
  • Tags with tag filtering
  • Text search across title/content/tags
  • Sorting by updated/created/title
  • JSON import/export with merge strategies
  • Autosave and explicit save
  • Event hooks via on / off
  • Runtime reconfiguration via config

5. API Overview

Primary methods:

// UI lifecycle
notebookV2.open()
notebookV2.close()
notebookV2.toggle()
notebookV2.destroy()

// Page operations
notebookV2.add(title, seed)
notebookV2.remove(pageId)
notebookV2.rename(pageId, newTitle)
notebookV2.duplicate(pageId)
notebookV2.update(pageId, updates)
notebookV2.getPage(pageId)
notebookV2.getActivePage()
notebookV2.listPages(filters)
notebookV2.setActive(pageId)

// Content helpers
notebookV2.setContent(pageId, text)
notebookV2.appendContent(pageId, text)
notebookV2.prependContent(pageId, text)

// Metadata helpers
notebookV2.pin(pageId)
notebookV2.unpin(pageId)
notebookV2.archive(pageId)
notebookV2.restore(pageId)
notebookV2.setTags(pageId, tags)
notebookV2.addTag(pageId, tag)
notebookV2.removeTag(pageId, tag)
notebookV2.setColor(pageId, cssColor)

// Filters and sorting
notebookV2.search(query)
notebookV2.filter(\{ query, tag, sort, showArchived \})
notebookV2.filterByTag(tag)
notebookV2.sort(sortMode)
notebookV2.resetFilters()

// Persistence
notebookV2.save()
notebookV2.exportPages()        // downloads json
notebookV2.exportPages("string") // returns json string
notebookV2.importPages()        // opens file picker
notebookV2.importPages(jsonString, \{ mergeStrategy: "append" \})
notebookV2.clearStorage()
notebookV2.reset(\{ clearStorage: true \})

// Shared profile (all generators using same profileStorageKey)
notebookV2.getProfile()
notebookV2.setProfile(\{ username: "my-name", password: "my-pass" \})
notebookV2.clearProfile()

// Config and state
notebookV2.config(options)
notebookV2.getState()

// Events
notebookV2.on("save", fn)
notebookV2.off("save", fn)

6. Example: Button Integration

<button onclick="notebookV2.open()">Open Notebook</button>
<button onclick="notebookV2.add('Session Plan')">Add Plan Page</button>
<button onclick="notebookV2.search('enemy lore')">Find Lore</button>

7. Keyboard Shortcuts

  • Ctrl/Cmd + S: save active editor
  • Ctrl/Cmd + N: add page
  • Ctrl/Cmd + F: focus search
  • Ctrl/Cmd + Shift + P: toggle pin on active page
  • Esc: close modal (if enabled)

Notes

  • Username/password profile data is stored in browser local storage under profileStorageKey. Keep in mind this is local-device convenience storage, not secure credential storage.
  • If kv is available in your generator, v2 can use it with storageDriver: "auto".
  • For multiple notebooks in one generator, set different storageKey values.
  • Check out more plugins at perchance.org/plugins.
