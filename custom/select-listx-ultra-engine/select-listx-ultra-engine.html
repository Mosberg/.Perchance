SelectListX Ultra Engine — How to Use

This page explains how to use the selectListX, selectListsX, and selectAllListsX functions, including all new features such as weights, filters, transforms, dedupe, seeded randomness, cycle detection, and more.

1. Basic Usage

selectListX(list)

Returns one random leaf from any nested structure.

// Example list
myList = ["apple", "banana", "cherry"];

// Usage
selectListX(myList);
// → "banana"

selectListsX(list, count)

Returns multiple random leaves.

selectListsX(myList, 3);
// → ["apple", "cherry", "banana"]

selectAllListsX(list)

Returns every leaf in the structure.

selectAllListsX(myList);
// → ["apple", "banana", "cherry"]

2. Supported Input Types

✔ Strings
✔ Numbers
✔ Booleans
✔ Arrays
✔ Objects
✔ Deeply nested structures
✔ Objects with value/text/label/name
✔ Objects with selectOne() or selectAll()
✔ Weighted objects

3. Weighted Selection

You can assign weights to influence probability:

myList = {
  weightMap: {
    common:  { value: "stone", weight: 10 },
    rare:    { value: "silver", weight: 3 },
    epic:    { value: "gold", weight: 1 }
  }
};

selectListX(myList);
// → "stone" (most likely)

4. Selecting a Range

Fixed number

selectListsX(myList, 5);

Random between min and max

selectListsX(myList, 2, 6);

Random from a list of options

selectListsX(myList, [1, 3, 5, 10]);

5. Global Settings (ListXConfig)

You can modify behavior using the global config object:

ListXConfig.debug = true;
ListXConfig.dedupe = true;
ListXConfig.shuffleArrays = true;
ListXConfig.seed = 12345;
ListXConfig.tryUntilValid = true;
ListXConfig.maxAttempts = 20;

Available Settings

  • debug — print internal steps
  • strict — throw errors on invalid structures
  • maxDepth — recursion limit
  • detectCycles — prevent infinite loops
  • seed — deterministic randomness
  • freeze — always return the same result
  • fallback — default return when empty
  • shuffleArrays — randomize arrays before selection
  • dedupe — avoid duplicates in selectListsX
  • preFilter — filter before selection
  • postFilter — filter after selection
  • transform — modify each result
  • keyBias — weight object keys
  • priorityKeys — keys to check first

6. Filters & Transforms

Pre-filter

ListXConfig.preFilter = x => x !== "forbidden";

Post-filter

ListXConfig.postFilter = x => x.length > 3;

Transform

ListXConfig.transform = x => x.toUpperCase();

7. Seeded Randomness

Use a seed for deterministic output:

ListXConfig.seed = 1000;

selectListX(myList);
// → always the same result

8. Freeze Mode

Always return the same value after the first selection:

ListXConfig.freeze = true;

selectListX(myList);
// → "banana"

selectListX(myList);
// → "banana" (always)

9. Cycle Detection

Prevents infinite loops in recursive structures.

ListXConfig.detectCycles = true;

10. Example: Complex Nested Structure

lootTable = {
  common: ["rope", "torch", "bread"],
  rare: {
    weightMap: {
      gem: { value: "ruby", weight: 2 },
      relic: { value: "ancient coin", weight: 1 }
    }
  },
  epic: {
    chest: {
      gold: ["bar", "coins"],
      artifact: ["idol", "tablet"]
    }
  }
};

selectListX(lootTable);

11. Example: Selecting Many

selectListsX(lootTable, 3);
// → ["torch", "ruby", "idol"]

12. Example: Getting All Leaves

selectAllListsX(lootTable);
// → ["rope","torch","bread","ruby","ancient coin","bar","coins","idol","tablet"]

13. Troubleshooting

  • Returns "(no listx found)" — list was empty or invalid
  • Returns "(cycle detected)" — recursive loop found
  • Returns same value repeatedly — freeze mode or seed enabled
  • Duplicates appear — disable dedupe

14. Summary

The SelectListX Ultra Engine is a powerful, flexible, and extensible random selection system designed for Perchance generators, RPG systems, loot tables, NPC creation, and any nested data structure.
