Dependency Graph Kit

Model module relationships, detect cycles, sort execution order, and compute blast radius for changes.

graph = \{import:dependency-graph-kit\}

Graph Building

addNode, addDependency, removeNode, removeDependency

Analysis

hasCycle, topoSort, dependencies, dependents, affected

Maintenance

nodeList, clear, exportJson, importJson for long-term management.

Use Cases

Load orders, plugin startup sequencing, and data transform planning.

Example Pattern

graph = \{import:dependency-graph-kit\}

\[graph.addDependency("runtime", "ui", "state")\]
\[graph.addDependency("runtime", "state", "config")\]

Order = \[graph.topoSort("runtime", " -> ")\]
Cycle = \[graph.hasCycle("runtime")\]
