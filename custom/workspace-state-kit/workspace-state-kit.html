Workspace State Kit

Workspace State Kit

Namespaced runtime state for larger generators with optional localStorage persistence and JSON migration helpers. 

stateKit = \{import:workspace-state-kit\}

Core State

set, get, exists, remove, keys, size, clear

UI Toggles

toggle, increment for counters, boolean flags, and mode switching.

List State

push and pop support list-like state without custom boilerplate.

Migration

exportJson and importJson to move state across versions.

Example Pattern

stateKit = \{import:workspace-state-kit\}

          \[stateKit.set("profile", "theme", "neon", "persist")\]
          Theme = \[stateKit.get("profile", "theme", "classic", "persist")\]

          \[stateKit.increment("profile", "runs", 1, "persist")\]
          Runs = \[stateKit.get("profile", "runs", 0, "persist")\]

          \[stateKit.push("profile", "recentScenes", "forest-night", 10, "persist")\]
          Snapshot = \[stateKit.exportJson("profile")\]

Tip: use separate namespaces for profile, session, editorUI, and debug state.
