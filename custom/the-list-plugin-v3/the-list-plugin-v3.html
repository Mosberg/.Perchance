The List Plugin v3

The List Plugin v3 provides a unified, hierarchical, leaf-aware selection engine for Perchance. It supports true uniqueness, weighted selection, path-based access, filtering, and more.

Import it into your lists editor like this:

listUtils = \{import:the-list-plugin-v3\}

Available functions

  • listUtils.selectListX(list, options?) — Select ONE leaf.
  • listUtils.selectListsX(list, countOrOptions?) — Select MANY leaves.
  • listUtils.selectAllListsX(list, options?) — Return EVERY leaf.
  • listUtils.selectPathX(root, path, options?) — Resolve a path and select.
  • listUtils.selectWeightedX(list, options?) — Weighted choice.
  • listUtils.shuffleListX(list, options?) — Shuffle leaves.
  • listUtils.sampleListX(list, n, options?) — Sample without replacement.

Example

listUtils = \{import:the-list-plugin-v3\}

// Select one random male name
[listUtils.selectListX(character.identity.name.first.male)]

// Select 3 unique positive traits
[listUtils.selectListsX(character.personality.traits.positive, \{
  count: 3,
  unique: true,
  separator: ", "
\})]

// Get all species, sorted
[listUtils.selectAllListsX(character.identity.species, \{
  sorted: true,
  asText: true,
  separator: ", "
\})]

// Select a hair color from a path
[listUtils.selectPathX(character, "appearance.hair.color", \{
  fallback: "brown"
\})]

// Weighted selection
[listUtils.selectWeightedX(character.identity.species, \{
  weightsKey: "weight"
\})]

Options Reference

\{
  count: 1,         // Number of items to select (for selectListsX)
  min: 1,           // Minimum count (for random ranges)
  max: 1,           // Maximum count (for random ranges)
  unique: false,    // Ensure unique selections
  seed: null,       // Seed for reproducible randomness
  fallback: "(no result)", // Fallback value if selection fails
  maxDepth: 1000,   // Maximum recursion depth
  separator: ", ",  // Separator when joining as text
  flatten: true,    // Flatten nested structures
  sort: false,      // Sort the results
  shuffle: false,   // Shuffle the results
  returnMeta: false, // Return metadata instead of values
  includeObjects: false, // Include non-leaf objects
  weightsKey: "weight", // Key for weights
  valueKeys: ["value", "text", "label", "name"], // Keys for values
  ignoreKeys: ["description", "meta", "weight", "tags"], // Keys to ignore
  filter: null,     // Function to filter items
  asText: false     // Return as joined string (for selectAllListsX)
\}

Notes:

  • selectListX always returns one resolved leaf (or fallback).
  • selectListsX supports count as a number, range, or options object.
  • selectAllListsX returns all leaves, optionally filtered/sorted.
  • Weighted selection uses the weightsKey (default "weight").
  • Uniqueness is enforced when unique: true.

Examples:

Random identity: [listUtils.selectListX(character.identity)]

Random male name: [listUtils.selectListX(character.identity.name.first.male)]

3 random skills: [listUtils.selectListsX(character.skills.combat, 3, \{separator:", "\})]

All species: [listUtils.selectAllListsX(character.identity.species, \{asText:true, separator:", "\})]

Hair color from path: [listUtils.selectPathX(character, "appearance.hair.color", \{fallback:"brown"\})]
