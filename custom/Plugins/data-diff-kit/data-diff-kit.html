Data Diff Kit

Detect structural changes, patch nested objects by paths, and create deterministic update summaries.

diffKit = \{import:data-diff-kit\}

Diffing

diff, changedKeys, summary, diffJson, equal

Path Ops

pathGet, pathSet, pathDelete for precise nested mutations.

Patching

patch and patchFromDiff apply controlled object updates.

Maintainability

Flattened path diffs make change review and syncing easier.

Example Pattern

diffKit = \{import:data-diff-kit\}

Before = \{"stats":\{"hp":10,"mp":5\},"name":"Ari"\}
After = \{"stats":\{"hp":12,"mp":5\},"name":"Ari","rank":"B"\}

Report = \[diffKit.diff(Before, After)\]
Keys = \[diffKit.changedKeys(Before, After, ", ")\]
