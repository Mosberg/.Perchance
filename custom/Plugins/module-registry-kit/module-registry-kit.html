Module Registry Kit

Module Registry Kit

Shared module catalog for reusable configs, data blocks, and cross-system contracts.

modules = \{import:module-registry-kit\}

Register

register, registerJson, merge, append

Read

use, useClone, pathGet, describe, exportJson

Mutate

pathSet, remove, clear, list, listByPrefix

Safety

freeze and isFrozen for immutable shared definitions.

Example Pattern

modules = \{import:module-registry-kit\}

\[modules.register("combat", \{crit:0.15, dodge:0.05\}, "clone")\]
\[modules.pathSet("combat", "weights.fire", 1.2, "clone")\]

Crit = \[modules.pathGet("combat", "crit", 0.1)\]
AllCombat = \[modules.use("combat")\]
Info = \[modules.describe("combat")\]

\[modules.freeze("combat")\]
Locked = \[modules.isFrozen("combat")\]
