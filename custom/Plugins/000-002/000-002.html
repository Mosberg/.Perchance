AI Text Generator Styles

A Perchance plugin for reusable AI writing styles, tones, and length controls.

1. Plugin Code for the Lists Editor

Save this code in the Lists Editor of your Perchance plugin page:

writingStyle
  creative and imaginative
  technical and precise
  poetic and lyrical
  persuasive and compelling
  academic and analytical
  casual and conversational
  dramatic and intense
  humorous and witty
  mysterious and atmospheric
  minimalist and stark

toneModifier
  enthusiastic
  melancholic
  authoritative
  whimsical
  serious
  playful
  somber
  uplifting
  neutral

lengthDirective
  Keep it brief (about 50 words).
  Write a medium-length piece (about 150 words).
  Provide a detailed, comprehensive response (about 300 words).

aiStylePrompt
  Style: [writingStyle]. Tone: [toneModifier]. [lengthDirective]

2. How to Import

In another Perchance generator, add this line at the top of the Lists Editor:

import ai-text-styles

Replace ai-text-styles with your plugin's actual URL slug. Once imported, all lists from the plugin become available in your generator's namespace.

3. How It Works

  • writingStyle — Picks a broad stylistic approach (e.g., poetic, technical).
  • toneModifier — Adds an emotional layer (e.g., melancholic, enthusiastic).
  • lengthDirective — Controls approximate word count.
  • aiStylePrompt — Merges the three lists above into a single prompt prefix ready for AI generation.

4. Usage Examples

Basic Generator Output

output
  [aiStylePrompt] Describe a city where gravity works sideways.

Using Lists Individually

output
  Compose a [writingStyle] paragraph that feels [toneModifier]. [lengthDirective]

5. Extending the Plugin

You can create new "locked" presets by writing fixed combinations:

poeticShort
  Style: poetic and lyrical. Tone: melancholic. Keep it brief (about 50 words).

techConcise
  Style: technical and precise. Tone: neutral. Keep it brief (about 50 words).
