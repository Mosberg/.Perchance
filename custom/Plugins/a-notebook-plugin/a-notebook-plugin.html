A Notebook Plugin

This plugin adds a notebook-style scratchpad to your generator. It stores pages in local browser storage (and can use kv when available), and includes page create/rename/delete, plus JSON export and import.

1. Import in Your Code Panel

notebook = \{import:a-notebook-plugin\}

2. Mount It in Your HTML Panel

Add this where you want the plugin to initialize (usually once, near the bottom of your HTML panel): 

\[notebook.mount()\]

This renders a floating "Notebook" button. Clicking it opens the modal UI.

3. Optional Configuration

You can pass options to mount (or init) to customize labels, storage key, button position, and behavior: 

\[notebook.mount(null, \{
  storageKey: "my_generator_notebook_v1",
  title: "Notes",
  buttonLabel: "Open Notes",
  buttonPosition: "bottom-left", // bottom-right | bottom-left | top-right | top-left
  autosave: true,
  autosaveDelay: 400,
  confirmDelete: true,
  openOnInit: false
\})\]

4. Programmatic API

Useful methods exposed by the plugin:

  • notebook.open() open modal
  • notebook.close() close modal
  • notebook.add(title) create a new page
  • notebook.rename(pageId, newTitle) rename page
  • notebook.remove(pageId) delete page
  • notebook.update(pageId, \{ title, content \}) update page
  • notebook.getPage(pageId) read one page
  • notebook.listPages() read all pages
  • notebook.save() save currently open editor values
  • notebook.exportPages() export as JSON
  • notebook.importPages() import from JSON
  • notebook.config(options) update settings after init

Quick Example

<button onclick="notebook.open()">Open Notebook</button>
<button onclick="notebook.add('Session Notes')">Add Page</button>

Tips:

  • If you import kv-plugin in your generator, notebook storage can use it automatically when available.
  • Keep one mount call per page. Calling mount() multiple times is unnecessary.
  • Use a custom storageKey if you run multiple notebook-enabled tools in the same generator.
  • Check out more plugins at perchance.org/plugins.
