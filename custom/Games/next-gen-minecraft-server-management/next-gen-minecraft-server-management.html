Comprehensive Features

📊

Real-Time Monitoring

Live server status, player counts, CPU, RAM, and network usage with customizable dashboard widgets.

👥

Multi-User Management

Granular permission system with role-based access control. Perfect for hosting providers and large communities.

🐳

Docker Integration

Full Docker Hub support with containerized instances. Isolate servers with custom resource limits.

📁

File Manager

Web-based file editor with syntax highlighting. Upload, download, and edit server files instantly.

💻

Console Access

Real-time console with command history, auto-complete, and color-coded output for easy debugging.

🔌

Plugin Management

Browse and install plugins from Spigot, Bukkit, and Paper with one-click updates and dependency resolution.

⏰

Task Scheduler

Automate backups, restarts, and commands with cron-style scheduling. Daily, weekly, or custom intervals.

💾

Automated Backups

Scheduled backups with compression, rotation policies, and one-click restoration. Store locally or cloud.

🌍

World Management

Create, delete, and switch between worlds. Import custom maps and manage dimension settings.

🔧

Server Properties Editor

Visual editor for server.properties with validation and descriptions for every setting.

🎮

Multi-Game Support

Manage Minecraft (Java/Bedrock), Terraria, Palworld, Squad, Project Zomboid, and 50+ Steam games.

🌐

Distributed Architecture

Control multiple physical servers from one panel. Scale horizontally across your infrastructure.

📱

Responsive Design

Fully mobile-optimized interface. Manage servers from your phone, tablet, or desktop.

🔒

Security First

2FA authentication, IP whitelisting, rate limiting, and encrypted connections by default.

🌍

Multi-Language

Full internationalization with 15+ languages including English, Chinese, German, Spanish, and Japanese.

🎨

Customizable UI

Drag-and-drop dashboard builder. Create custom layouts with resizable cards and widgets.

📈

Analytics & Reports

Historical performance data, player join/leave tracking, and exportable usage reports.

🔔

Alert System

Discord, Slack, and email notifications for crashes, high load, or custom trigger conditions.

🚀

One-Click Deployment

Pre-configured templates for Vanilla, Spigot, Paper, Forge, Fabric, and mod packs from the marketplace.

🔗

API Access

RESTful API with webhooks for custom integrations, automation, and third-party tool connections.

🗺️

Live Map Integration

Embed Dynmap, BlueMap, or Pl3xMap directly in the dashboard for real-time world visualization.

💬

Chat Bridge

Connect in-game chat to Discord, Telegram, or web dashboard for seamless communication.

⚙️

Advanced Settings

JVM arguments, memory allocation, GC tuning, and startup flags with performance recommendations.

🔍

Log Analysis

Searchable logs with filters, regex support, and automatic error detection with suggested fixes.

🪟

Windows

Download the installer and run. No dependencies required - everything is bundled.

Download .exe
🐧

Linux

One-line installation script with automatic setup and systemd service creation.

curl -sSL install.sh | bash
🐳

Docker

Deploy with docker-compose for containerized setup with persistent volumes.

docker-compose up -d
