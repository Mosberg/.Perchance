About This Validator

Beyond the Bobber — AI JSON Validator is a specialized tool for validating game data against schema-first rules. It uses AI to provide explanations, generate sample data, and fix validation errors.

Features

  • Schema validation with detailed error reporting
  • AI-powered explanations of validation results
  • AI generation of sample JSON data
  • AI-assisted error fixing
  • Import/export of JSON files
  • Validation history tracking
  • Customizable themes and settings
  • Custom schema support
  • Keyboard shortcuts
  • Find and replace functionality
  • Minify and copy JSON
  • Validation summary for all schemas

Schema Support

Currently supports schemas for: Tools, Tools Recipes, Raw Fish, Cooked Fish, Dishes, Rarity, and Custom Schemas.

Keyboard Shortcuts

  • Ctrl+F - Open find/replace
  • Ctrl+Enter - Validate current JSON
  • Ctrl+S - Export JSON
  • Ctrl+G - Generate with AI
  • Ctrl+E - AI Explanation
  • Ctrl+A - Validate all schemas
  • Ctrl+R - Auto-fix errors
