Pipeline Orchestrator Kit

Create reusable processing pipelines with configurable steps, tap points, and rich run reports.

pipelines = \{import:pipeline-orchestrator-kit\}

Pipeline Control

create, addStep, setEnabled, removeStep, clear, clearAll

Execution

run and runReport support strict and tolerant execution modes.

Step Types

Transform steps mutate values while tap steps observe without mutating.

Metadata

describe, listPipelines, listSteps track structure and usage.

Example Pattern

pipelines = \{import:pipeline-orchestrator-kit\}

\[pipelines.create("render", "replace")\]
\[pipelines.addStep("render", "trim", (value) => String(value).trim())\]
\[pipelines.addStep("render", "upper", (value) => String(value).toUpperCase())\]

Output = \[pipelines.run("render", "  hello world  ")\]
Report = \[pipelines.runReport("render", "  hello world  ")\]
