Event Lanes Kit

Queue-driven event orchestration for decoupling UI triggers from generator logic.

events = \{import:event-lanes-kit\}

Emit

emit, emitUnique, emitBatch

Consume

peek, pull, pullAll, drain

Observe

count, latest, summary, laneJson

Control

clear and trim for lifecycle and memory bounds.

Example Pattern

events = \{import:event-lanes-kit\}

\[events.emit("ui", "action:generate", \{tab:"main"\}, "toolbar")\]
\[events.emitUnique("ui", "action:generate", \{tab:"main"\}, "toolbar")\]

Pending = \[events.count("ui")\]
NextAction = \[events.pull("ui", "action:generate")\]
Stats = \[events.summary("ui")\]

\[events.trim("ui", 150)\]
