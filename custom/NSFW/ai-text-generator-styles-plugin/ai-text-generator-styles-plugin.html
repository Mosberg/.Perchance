2. How to import the plugin

In another Perchance generator, add this line at the top of the Lists Editor: 

import ai-text-generator-styles-plugin

Replace ai-text-generator-styles-plugin with your plugin's actual URL slug. Once imported, all lists from the plugin become available in your generator's namespace.

3. What this plugin gives you

  • writingStyle — Broad stylistic approach (creative, technical, poetic, narrative, etc.).
  • toneModifier + toneIntensity — Emotional flavor and strength (serious, playful, ominous, subtle, strong, etc.).
  • lengthDirective + lengthType — Approximate word count and structural length (one sentence, short paragraph, long-form article, etc.).
  • pointOfView — First person, second person, third person limited/omniscient, or mixed.
  • targetAudience — Children, teens, general readers, experts, executives, and more.
  • formatType — Prose, bullet list, steps, dialogue-only, email, social post, documentation, FAQ, etc.
  • complexityLevel — From very simple language to highly technical jargon-heavy writing.
  • styleConstraints — Extra rules (no bullets, punchy sentences, twist at the end, call to action, tense control, etc.).
  • aiStylePrompt — A full, verbose style prefix combining all of the above.
  • aiStylePrompt_compact — A shorter version if you want less prompt text.
  • preset_… — Named, “locked” presets for consistent behavior across generators.

4. Basic usage examples

4.1 Random style for a creative prompt 

output
  [aiStylePrompt]
  Describe a city where gravity works sideways.

4.2 Using lists individually 

output
  Compose a [writingStyle] paragraph that feels [toneModifier] and [toneIntensity].
  [lengthDirective]
  POV: [pointOfView]
  Audience: [targetAudience]
  Format: [formatType]

4.3 Using a locked preset 

output
  [preset_poeticShortMelancholic]
  Describe the moment before a storm hits a quiet town.

5. Integrating with your AI text generator

If your generator exposes a list like generateText that calls an AI API, you can feed the style prompt directly into it.

5.1 Single-call example 

// In your main generator's Lists Editor:
import ai-text-generator-styles-plugin

// Example: topic list
topic
  Describe a city where gravity works sideways.

// Example: final output
output
  \[generateText:
    prompt=\[aiStylePrompt\]
           Topic: \[topic\]
  \]

5.2 Using a preset with your AI call 

output
  \[generateText:
    prompt=\[preset_techDocConciseNeutral\]
           Explain how to set up continuous integration for a small web app.
  \]

6. Advanced customization ideas

  • Genre-specific presets: Create preset_fantasyEpic, preset_scifiHard, etc., that lock in style, tone, POV, and length.
  • User-facing toggles: Expose writingStyle, toneModifier, or formatType as dropdowns in your UI and pass the chosen values into the prompt.
  • Consistency across tools: Reuse the same presets in multiple generators (story prompts, blog outlines, documentation helpers) to keep your “house style” consistent.
  • A/B testing: Randomly pick between two presets to compare which style performs better for your use case.

7. Included presets (quick reference)

  • preset_poeticShortMelancholic — Short, poetic, melancholic, simple language, metaphor-friendly.
  • preset_techDocConciseNeutral — Concise, technical documentation, neutral tone, jargon allowed.
  • preset_marketingUpliftingMedium — Medium-length, marketing style, uplifting tone, ends with a call to action.
  • preset_storyLongAtmospheric — Long narrative, mysterious and atmospheric, twist near the end.
  • preset_socialPostPlayfulUltraShort — Ultra-short, playful social media style, punchy sentences.

Duplicate and rename these presets to build your own style library—once they exist in the plugin, every generator that imports it can reuse them instantly.
