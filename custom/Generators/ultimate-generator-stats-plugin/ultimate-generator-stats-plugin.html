Ultimate Generator Stats Plugin

This plugin lets you display live statistics for any Perchance generator — including your own or others. It supports multiple output formats, compact view counters, short/long time formats, badges, JSON output, and more.

Installation

Place this in your Perchance Code panel:

generatorStats = \{import:ultimate-generator-stats-plugin\}

Basic Usage

Show stats for the current generator:

Views: [generatorStats("views")]
Last edited: [generatorStats("lastEditTime")]

Stats for Another Generator

Pass the generator name as the first argument:

[generatorStats("dice-plugin", "views")]
[generatorStats("background-image-plugin", "lastEditTime")]

Extended Data Types

The Ultimate version adds many new output formats:

[generatorStats("viewsRaw")]          → raw integer
[generatorStats("viewsShort")]        → compact (1.2K, 3.4M)
[generatorStats("viewsCompact")]      → K / M / B formatting

[generatorStats("lastEditTimeShort")] → short relative (3d, 2h, 5m)
[generatorStats("lastEditTimeMs")]    → milliseconds since last edit
[generatorStats("lastEditTimeIso")]   → ISO timestamp
[generatorStats("lastEditTimestamp")] → raw epoch timestamp

[generatorStats("badge")]             → "1.2K views • edited 3 days ago"
[generatorStats("json")]              → full JSON stats object

Examples

Views: [generatorStats("viewsShort")]
Last edited: [generatorStats("lastEditTimeShort")]
Full badge: [generatorStats("badge")]

Other generator:
[dice-plugin] → [generatorStats("dice-plugin", "badge")]

Notes

  • All original plugin behavior is fully supported.
  • Works with any public Perchance generator.
  • Automatically caches results for performance.
  • Outputs update asynchronously once data loads.
