text2image-framework-v4

This module is a Perchance framework wrapper. Use \{import:text2image-framework-v4\} in generators to load the advanced suite stack.

Includes state manager, seed engine, prompt processor, modifier groups, content filtering, metadata manager, and QoL utilities.

Engine compatibility modes: core, moss-v2, vulkcat-v3, and auto (default).

Configure with: settings.frameworkV4.engine = core|moss-v2|vulkcat-v3 or settings.frameworkV4.preferVulkcat = true.
