Python API Examples

Perchance functionality can be accessed in Python using HTTP requests to public generator URLs:

Basic Text Generation

import requests

# Example: Fetch output from a Perchance generator
generator_url = "https://perchance.org/api/example-generator"
response = requests.get(generator_url)

if response.status_code == 200:
    result = response.text
    print("Generated output:", result)
else:
    print("Error:", response.status_code)

Custom Generator with Parameters

# Using your own generator with parameters
url = "https://perchance.org/your-generator-name/export/text/plain"
params = {
    "prompt": "A fantasy creature",
    "temperature": 0.7,
    "max_tokens": 150
}

try:
    response = requests.get(url, params=params)
    response.raise_for_status()  # Raises an exception for 4XX/5XX errors
    
    print("Custom generator output:", response.text)
except requests.exceptions.RequestException as e:
    print("Request error:", e)

Image Generation

# Generate an image with custom parameters
image_url = "https://perchance.org/api/image-generator"
params = {
    "prompt": "A futuristic cityscape",
    "width": 1024,
    "height": 768,
    "style": "realistic"
}

try:
    response = requests.get(image_url, params=params, stream=True)
    response.raise_for_status()
    
    # Save the image to a file
    with open("generated_image.png", "wb") as f:
        for chunk in response.iter_content(1024):
            f.write(chunk)
    
    print("Image saved successfully!")
except requests.exceptions.RequestException as e:
    print("Request error:", e)

KV Storage via HTTP (Limited)

# Note: Perchance KV storage is primarily designed for JavaScript
# For Python, you would need to create a custom API endpoint

# Example of a hypothetical KV API (not currently available)
kv_url = "https://your-perchance-site.com/api/kv"

# Set a value
set_data = {"key": "user_name", "value": "John Doe"}
response = requests.post(kv_url, json=set_data)

# Get a value
get_data = {"key": "user_name"}
response = requests.get(kv_url, params=get_data)
if response.status_code == 200:
    print("Retrieved value:", response.json().get("value"))

Notes:

  • JavaScript APIs are only available in Perchance's browser environment
  • Python requires HTTP requests to public generator URLs
  • All JavaScript operations require internet connection
  • Image generation may take 10-30 seconds
  • KV storage is persistent across sessions
  • Python KV operations require a custom API endpoint
