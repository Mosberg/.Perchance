System Guide

Everything you need to know about PerGens

Search & Tag Filters

Click on the search bar to reveal the category filter buttons. You can type a generator name directly, or select a category (like Image or Chat) to filter results. You can combine text search with tag filters at the same time for more precise results. Active tags appear as chips below the bar — click ✕ on any chip to remove it.

Category Tags

Each generator carries one or more category tags describing the type of content it produces. To add a tag to your generator, enter your generator type in the List Panel on the left side in perchance.

Text — Text generation & writing Image — AI image creation Story — Narratives & storytelling Game — Interactive games Code — Code generation Chat — Conversational AI Art — Creative art tools Prompt — Prompt engineering

Card Badges

Badges appear in the top-left corner of a card and indicate the generator's status:

NewUpdated within the last 24 hours
HotVery high view count (+500k)
PinnedFeatured / staff-picked generator
TrendingRising fast in recent activity

Sorting Options

New: Shows the most recently updated generators first — useful for keeping up with the latest uploads.

Popular: Sorted by total view count, with the most viewed generators at the top.

Trending: Balances views with recency, so generators picking up steam recently rank higher than old generators sitting on a large view count.

A-Z: Alphabetical order by generator name — handy when you're looking for something specific.

Oldest: Shows the oldest generators first.

Liked: Shows only the generators you have liked — your personal saved list.

Hidden: Shows generators you have hidden via Dislike. You can review them here and un-hide any by clicking Dislike again.

Add a Generator

Click the + button in the navbar. Paste any Perchance generator URL (e.g. perchance.org/my-generator) and it will be fetched and added to your list automatically. Manually added generators are saved in your browser and persist after page reloads.

Like & Hide

Each card has two small action buttons:

Like (👍): Saves the generator to your favorites list. Access it anytime via the Liked sort option. Preferences are stored locally in your browser.

Dislike (👎): Hides the generator from the main list. You can restore it at any time via the Hidden sort, then click Dislike again to un-hide it.

Display Settings

Personalize how generator cards are shown. These preferences are saved locally in your browser.
