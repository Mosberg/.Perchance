jsonX Plugin Guide

Perchance Plugin Reference

jsonX

jsonX is a utility toolkit for JSON/JSONC parsing, type checks, deep path access, object and array transformations, lightweight validation, and HTML string helpers.

It is designed to give safe defaults in most operations, so list code can stay compact. 

// Import in your generator
jsonX = \{import:jsonx\}

JSONC Core

Parse JSON with comment support and clone or stringify safely.

stripJsonc(text)

Removes // line comments and /* block comments */ from a string.

jsonX.stripJsonc('\{"a":1, // keep\n"b":2\}')

parse(text, fallback)

Parses JSONC. Returns fallback instead of throwing when parsing fails.

jsonX.parse(userJsonText, \{ok:false\})

parseStrict(text)

Parses JSONC and throws on invalid JSON. Use when you want hard failure.

let data = jsonX.parseStrict(configText)

stringify(value, space)

Safe JSON stringify. Uses optional indentation and returns empty string on failure.

jsonX.stringify(payload, 2)

clone(value)

Deep clones via JSON round trip. Returns original value if cloning fails.

let copy = jsonX.clone(original)

Type Helpers

Check types and coerce values for robust list logic.

typeOf(value)

Returns one of: null, array, string, number, boolean, object, undefined, function, etc.

jsonX.typeOf([1,2]) // "array"

isArray(value)

True if value is an array.

jsonX.isArray(input.tags)

isObject(value)

True only for non-null plain objects (not arrays).

jsonX.isObject(input.settings)

isString(value)

True if value is a string.

jsonX.isString(input.name)

isNumber(value)

True if value is a number and not NaN.

jsonX.isNumber(input.seed)

isBoolean(value)

True if value is exactly boolean true or false.

jsonX.isBoolean(input.enabled)

isNull(value)

True when value is null.

jsonX.isNull(input.theme)

isUndefined(value)

True when value is undefined.

jsonX.isUndefined(input.mode)

ensureArray(value)

Returns \[\] for null/undefined, returns value if already array, else wraps value in array.

jsonX.ensureArray(input.tags)

ensureObject(value)

Returns value if plain object, else \{\}.

let opts = jsonX.ensureObject(input.options)

toNumber(value, fallback)

Coerces with Number(). Returns fallback on NaN.

jsonX.toNumber(input.count, 0)

toBoolean(value, fallback)

Converts booleans, common boolean-like strings, and 0/1 numbers.

jsonX.toBoolean(input.debug, false)

Path Helpers

Read, write, and delete deeply nested values by dot path.

splitPath(path)

Converts a dot path string to array. If already array, returns it directly.

jsonX.splitPath("user.profile.name")

get(obj, path, fallback)

Returns deep value when present, fallback if any segment is missing.

jsonX.get(user, "profile.name", "Unknown")

has(obj, path)

True if every path segment exists on the object chain.

jsonX.has(user, "profile.avatar")

set(obj, path, value)

Creates missing objects on the path and sets the target value.

jsonX.set(user, "profile.name", "Mosberg")

del(obj, path)

Deletes key at path if reachable; otherwise leaves object unchanged.

jsonX.del(user, "profile.temp")

Merge and Patch

Combine objects with shallow or deep behavior.

assign(target, source)

Shallow assignment: copies source keys onto target.

jsonX.assign(baseConfig, patch)

mergeDeep(target, source)

Deep merge for objects, concatenates arrays, replaces mismatched types.

jsonX.mergeDeep(defaults, overrides)

Object Utilities

Extract, reshape, and inspect plain object values.

keys(obj)

Returns object keys or \[\] if not plain object.

jsonX.keys(settings)

values(obj)

Returns object values or \[\] if not plain object.

jsonX.values(settings)

entries(obj)

Returns array of \[key, value\] pairs.

jsonX.entries(settings)

pick(obj, keys)

Builds object containing only selected keys.

jsonX.pick(user, \["name","id"\])

omit(obj, keys)

Builds object excluding selected keys.

jsonX.omit(user, \["password","token"\])

Array Utilities

Operate on list-like data with safe fallbacks.

listLength(list)

Returns array length or 0.

jsonX.listLength(tags)

listGet(list, index, fallback)

Returns item at index or fallback.

jsonX.listGet(tags, 1, "none")

listRandom(list, fallback)

Returns random item or fallback for empty/non-array.

jsonX.listRandom(options, "default")

listMap(list, fn)

Maps list with function. If fn missing, returns shallow copy.

jsonX.listMap(nums, n => n * 2)

listFilter(list, fn)

Filters list with function. If fn missing, returns shallow copy.

jsonX.listFilter(users, u => u.active)

listFind(list, fn, fallback)

Returns first matching item or fallback.

jsonX.listFind(users, u => u.id===7, null)

listSortBy(list, fn)

Returns sorted copy using computed key function.

jsonX.listSortBy(items, x => x.rank)

listUnique(list, keyFn)

Deduplicates values. Without keyFn, uses JSON.stringify(value).

jsonX.listUnique(users, u => u.id)

Validation

Small helpers for quick shape checks.

requireKeys(obj, keys)

Returns missing keys from the required set.

jsonX.requireKeys(profile, \["id", "name"\])

validateShape(obj, shape)

Compares actual value types to expected types. Returns error strings for mismatches. Use any to skip a key. 

jsonX.validateShape(user, \{id:"number", name:"string", meta:"any"\})

HTML Helpers

Build HTML safely from JSON-like data in generator scripts.

html(text)

Returns a plain string (no escaping).

jsonX.html("<b>raw</b>")

escapeHtml(text)

Escapes &, <, >, ", and '. Use this for untrusted text.

jsonX.escapeHtml(userInput)

htmlBlock(text, className)

Returns a div string with optional escaped class attribute.

jsonX.htmlBlock("Hello", "card")

htmlAttr(name, value)

Builds one HTML attribute string with proper escaping rules.

jsonX.htmlAttr("title", userInput)

htmlTag(tag, attrs, innerHtml)

Builds complete tag string from an attrs object and body html.

jsonX.htmlTag("a", \{href:"/", class:"btn"\}, "Home")

Common Recipes

Practical combinations that show how jsonX helpers fit together.

Safe config load

let raw = localStorage.myConfig
let cfg = jsonX.parse(raw, \{\})
cfg = jsonX.mergeDeep(\{theme:"light", pageSize:20\}, cfg)

Read nested field with fallback

let author = jsonX.get(post, "meta.author.name", "anonymous")

Validate incoming payload

let missing = jsonX.requireKeys(payload, \["id", "title"\])
let errs = jsonX.validateShape(payload, \{id:"number", title:"string", tags:"array"\})

Build escaped markup from object data

let label = jsonX.escapeHtml(user.name)
let card = jsonX.htmlTag("div", \{class:"user"\}, label)

Behavior Notes

  • Dot paths are split by ., so keys containing literal dots are treated as nested path segments.
  • mergeDeep concatenates arrays instead of replacing them.
  • parseStrict throws parse errors; parse returns fallback instead.
  • listMap and listFilter return a shallow list copy if no function is provided.
  • html(text) does not escape content. escapeHtml(text) does.
