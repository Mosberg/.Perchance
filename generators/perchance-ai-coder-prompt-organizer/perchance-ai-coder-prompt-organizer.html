How to use
  1. Describe what you want to build in Main Goal.
  2. Click Auto-Generate Features to let AI break it into parts, or add features manually.
  3. Nest details under each feature using + Subfeature.
  4. Use Diagnose Goal to spot missing details and answer clarifying questions.
  5. Click Generate Optimized Prompt to produce a clean prompt for the Perchance AI Coder.
  6. Review with Diagnose Output, refine with Less/More Detail, then copy.
