Gameplay Instructions

1. Overview

- Objective: Build and simulate a world where characters live autonomously or through your interactions. Manage their stats (e.g., HP, energy, hunger), moods, and actions to create stories, scenarios, or experiments.

- Core Features:

- Start: Characters act on their own, moving, interacting, and chatting.

- Customization: Create places, rooms, objects, and characters with descriptions, images, and properties.

- Interactions: Characters can pick up objects, chat, change moods, and respond to events.

- UI Navigation: Use tabs and buttons to switch between managing characters, places, stats, logs, and chat history.

- Game Loop: Once started, the simulation runs in real-time. You can pause, restart, or reset it at any time.

2. Getting Started

Start by setting up your world. You'll need at least one place to begin the simulation.

- Step 2.1: Create a Place

1. Click the Places List tab at the bottom (button labeled "Places List").

2. In the "Places" panel, click Create New Place.

3. Fill in the form:

- Name: Give your place a unique name (e.g., "My Home").

- Description: Add details about the place (e.g., "A cozy house by the sea").

- Background Image URL: Enter a URL for an image (e.g., from Freepik) to set the visual background. Use templates by clicking Show Templates to select pre-made options like "Bedroom" or "Underwater."

- Background Color: Pick a color using the color picker.

- Background Image Size: Set the width and height (default: 962x532 pixels). You can resize it later in the editor.

4. Click Save Place.

5. The new place will appear in the list. Click Select next to it to make it the current place. This will load the place into the game grid.

- Step 2.2: Add Rooms to Your Place

Once a place is selected:

1. In the Places List panel, click Edit on your place.

2. In the Rooms section, click Create New Room.

3. Fill in the room form similar to the place form (name, description, background, etc.).

4. Save the room. It will appear in the room list for that place.

5. You can add objects to rooms later (see Step 2.4).

- Step 2.3: Create Objects

Objects are items characters can interact with (e.g., food, weapons).

1. In the Places List panel, while editing a place, go to the Objects section and click Create New Object.

2. Fill in the form:

- Name: E.g., "Apple".

- Type: Choose from options like "Food", "Weapon", "Holdable", or "Not holdable". This affects how characters interact with it.

- Image URL: Add an image (use templates via Show Templates for quick options).

- Description: Describe the object (e.g., "A juicy red apple that restores hunger").

- Image Size: Set width and height (default: 50x50 pixels).

3. Click Save Object. It will be added to the global objects list and can be placed in your current place or room.

- Step 2.4: Add Objects to Places or Rooms

1. In the Places List or Room panel, find the objects section.

2. Click Add next to an object to place it in the current place or room.

3. Objects will appear in the game grid for interaction.

- Step 2.5: Create Characters

1. Click the Characters List tab.

2. Click Create New Character.

3. Fill in the form:

- Name: E.g., "Alice".

- Description: Add personality details (e.g., "Friendly and adventurous").

- Image URL: add or select from templates (click Show Templates for options like "Girl" or "Cat").

- Image Size: Set width and height (default: 200x200 pixels).

- Initial Mood: Choose from options like "Happy", "Sad", etc.

4. Click Save Character. The character will be added to the list and appear in the game grid of the current place.

5. Assign characters to rooms by editing them or using the Character Stats panel.

3. Running the Simulation

Once you have a place, rooms, objects, and characters, start the game.

- Step 3.1: Start the Game

1. In the top controls, click Start.

2. Characters will begin moving autonomously, interacting with objects, and chatting based on their moods and stats.

3. Watch the game grid for actions like characters walking, picking up objects, or talking.

- Step 3.2: Interact with Characters and Objects

- Select a Character: In the Characters List, click Select next to a character. This opens the Character Stats panel.

- View stats (e.g., HP bar) and control actions like moving to a room or using an object.

- Click Chat as Selected Character to start a conversation with another character.

- In the stats panel:

- Move to Room: Select a room from the dropdown and click Move.

- Use Object: From the dropdown, select an object and click Use.

- Edit Mood: Change the character's mood (e.g., from "Happy" to custom).

- Drag and Drop: Click and drag characters or objects in the game grid to move them. If a character is holding an object, it moves with them.

- Object Interactions: Characters can automatically grab, use, or drop objects. For example:

- If a character is hungry and near food, they might eat it, restoring hunger.

- Weapons might make them aggressive.

- Step 3.3: Chat and Conversations

1. In the Character Stats panel, click Chat as Selected Character.

2. Select another character and enter a message.

3. The AI generates a response, and characters may perform actions based on the conversation (e.g., move, grab an object).

4. View chat history in the Chat History tab. You can filter, copy, or clear conversations.

5. Characters chat only in pairs of 2 (e.g., Character A with Character B). Each pair maintains its own isolated conversation history, meaning characters will only remember and reference discussions with that specific partner in future interactions.

- Step 3.4: Monitor and Manage

- Stats Tab: Track a character's health, energy, and other stats. Low stats might lead to mood changes.

- Activity Log Tab: See a log of all actions (e.g., "Alice picked up the Apple").

4. Advanced Features

- Autonomous Mode: Characters act on their own (e.g., wander, interact). Enable this by starting the simulation.

- Editing and Duplication:

- Edit any character, place, room, or object by selecting it and using the edit buttons.

- Duplicate characters or objects for quick creation.

- Reset or Restart: Use Refresh to restart the simulation without losing data, or Reset to wipe everything.

- Save and Load: The Game progress is automatically saved in your browser's local storage, so you can pick up where you left off anytime.

5. Controls and Tips

- Top Buttons:

- Start/Stop: Toggles the simulation.

- Refresh: Restarts the simulation with current data.

- Reset: Deletes all data (use with caution).

- Bottom Tabs:

- Characters List: Manage characters.

- Places List: Manage places and rooms.

- Character Stats: Control a selected character.

- Activity Log: View game events.

- Chat History: Review conversations.

- Tips:

- Use templates for quick image selection to speed up creation.

- Experiment with moods and interactions to create dynamic stories.

- If characters get stuck, manually move them or refresh the simulation.

Have fun simulating life in your AI world!😊
