▸ WHAT IS THIS?

A big shared pack of custom emoji images for the Perchance comments plugin. Add one line to your generator's commentsOptions and your chat gets dozens of meme/reaction/character emojis that everyone can use by typing :name:.

.JPG.WEBP.GIF.PNG  formats supported

▸ HOW TO USE IT

  1. Make sure your generator already uses the comments plugin (comments = \{import:comments-plugin\} in your main.pjs).
  2. In your main.pjs, find (or create) a commentsOptions list.
  3. Add this line inside it so Perchance pulls in this shared emoji pack: 
    commentsOptions
  customEmojis = \{import:the-epic-emoji-list\}// pulls in every emoji below
  4. Render the comments widget in your index.html like normal and you should get this: 
    

        
    [comments(commentOptions2)]
    
        In the code i have the list for this comment section has commentOptions2 since i already have the suggestion comments as commentOptions
      
    5. 
      
  5. That's it! Users type :cat_jam:, :Sans_PTSD:, etc. in the chat
          and the image appears inline.

▸ SUGGEST A NEW EMOJI

    

      Want an emoji added to the shared pack? Drop it in the comments box below using this format:
    


EMOJI_NAME = https://user.uploads.dev/file/stringgoeshere

    
    
      
  • Name must be lowercase letters, numbers, and underscores only (e.g. happy_bread_prick).

    • 
      
  • NSFW emojis are NOT allowed. Suggesting one = instant ban. (Yes, this is spelled out right here.)
    • 
      
  • Swear words in names are fine. The N-word is not.
