What Is the Codex?

The Codex (at perchance.org/the-epic-codexv2) is a community-driven index of user-made entries — think of it as a wiki or directory for the AI Image Generator community. Each "codex" is a card created by a user that holds info like an avatar, username, title, description, tags, and links.

  • Created by BinaryCodedCat, built for BinaryCodedCat's ai image gen.
  • Anyone can browse, search, and add their own codex entries inspired by the Furdex — no sign-up required.
  • Entries are PG-13 only — no NSFW content allowed.

How to Use the Codex

1Browse & Search

Use the search bar at the top of the Codex page to filter entries by username, title, or tags. The placeholder shows how many codexes are in the database (e.g. "Search 320 Codexes...").

2Share a Search

After searching, click the share button next to the search bar. It copies a URL like https://perchance.org/the-epic-codexV2?q=your+search that opens the page already filtered. You can also just edit the ?q= URL parameter directly.

3Create a New Codex

Click the floating pen button (bottom-right) to open the "Create New Codex" panel. Fill in:

  • Avatar — optional image URL (e.g. an imgur/gif link).
  • Username * — your name/handle (required).
  • Title * — a name for the codex, like mygallery or private-channel (required).
  • Custom URL — optional alias; only letters, numbers, hyphens, underscores. Example: setting mygallery produces a codex#mygallery link.
  • Description * — Markdown-supported text. Use the toolbar for bold, italic, underline, headers, code blocks, links, spoilers, and dividers. Custom emojis are not supported; share image links instead.
  • Date / Updated — when the codex was made and last updated.
  • Tags — pick from preset tags or add custom comma-separated ones.

Click Preview to see how it will look, then Submit to publish. Use clear all to reset the form.

4Filter & Discover

Use the filter icon to narrow entries by tag.

Markdown Cheat Sheet

The description field supports Markdown via the toolbar. Quick reference:

  • **bold** → bold
  • *italic* → italic
  • __underline__ → underline
  • # Header → large header (### for small)
  • ~~strikethrough~~ → strikethrough
  • `inline code` → code
  • ```code block``` → multi-line code
  • (link-text)(https://link) → hyperlink (wrap link-text in square brackets when you type it)
  • ||spoiler|| → hidden spoiler text
  • --- on its own line → horizontal divider

Frequently Asked Questions

Do I need an account to use the Codex?

No. The Codex is fully usable without sign-up. Entries are stored locally in your browser (via the codex-items plugin) and shared through the public index.

What's the difference between a codex and a regular Perchance generator?

A codex is a lightweight directory entry — a card with avatar, name, description, tags, and links — rather than a full generator. It's meant for organizing community profiles, galleries, channels, and lore.

Can I share a link to a specific search?

Yes. Run a search, then click the share button — it copies a URL like https://perchance.org/the-epic-codexV2?q=fursona. Opening that link auto-filters the list.

What is the "Custom URL" field?

It's an optional alias that becomes part of your codex's identity (e.g. entering mygallery makes a codex#mygallery link). Only a-z A-Z 0-9 - _ are allowed; other characters are stripped as you type.

Who made the Codex?

The Codex is built by BinaryCodedCat, inspired by the Furdex. It's G2G (generator-to-generator) friendly — open to networking and partnerships. Leave feedback in the generator's comment section or via this form.

Can I copy the Codex code?

The source notes that the code is closed-source and community-driven; do not copy, clone, or reuse it for any purpose. To network or partner, contact BinaryCodedCat through the channels above.

Quick Tips

  • Use the Preview button before submitting to catch formatting issues.
  • Tag entries accurately so others can find them via search and filters.
  • Keep descriptions concise; link out to longer galleries/wikis instead of pasting huge text.
  • Set the Updated date whenever you revise an entry so the index reflects freshness.
  • Keep descriptions PG-13 — no adult content allowed in the Codex.
