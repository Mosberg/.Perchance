MEMORY GENERATOR
Thanks for viewing Mem-Gen

🢁Prompt📑 - Upload prompt txt. Zipped downloads include .txt prompt.
🢁Prompt🏞️ - Upload an image prompt. (if tickbox on prompt is saved into image).
🡻Zipped - Download all generated images in a zip, save prompts as .txt
🧼Reset - Wipes all the generated images.
🌱Random Seed - Must be off if you are generating a same seed sequence.
🎛️Image Tags - Large tags menu for easy adding tags to your prompt.
💾Format - Final download format, .jpg .png or .webp for single/zipped downloads.
🎞️Slideshow - Displays all pages images as a setable FPS slide show.
💘Gallery - Click the GS (Gallery Save) small gray button on images.
Gallery images even if saved as html still have the prompt in them.
📝Notes - Allows to store snips of prompts and other notes in here.
✂️Crop - Issue! If you crop an image it has an odd prompt thing for regen.

IMAGE BUTTONS...
🗑️ Deletes the image. 5 sec change mind timer.
✨ Upscale and or filter this image.
✂️ Crop this image to cut out a part liked. Result will be upscaled to x768x
🔁 Regenerate this image with the same seed.
♻️ Reuse this image prompt + seed.
⬇️ Download this image.
🔍 View this image full size.
🪄Enhance. Image wil be given user set filters for sharpness contrast, saturation, smoothing, denoise and brightness settings automatically.
Images GS Button.
Save this image to custom html gallery that can be downloaded uploaded appended.

OTHER NOTES...
❕Cropped aspect changed images regen at the aspect cropped at. (A different img).
❕The Crop feature is very handy no size loss fix for errors and aspect change.
❕Run menu - Each 1 "Run" in the menu generates 3 images.
❕EXIF. This generator reads perchance AND pollinations images with prompts in them.
❕If you created alot of images with the same seed you can import the zipped file to
https://perchance.org/ufo-ivvi and it will read the zip for all the images loading them for making a video. This generator does alot of other things with videos like image to video.
▫️Jumble Prompt - Enables mashing up your prompt wildly for different results.
▫️Line, by, line - Best used with lonnnnng descriptive scenes seperated by ,
▫️Randomze - forces line by line to start randomly instead from top of prompt.
▫️Parallel Sets - !!! This feature is a to async batch gen images (95% WiP).

While this generator is handy you may find
https://perchance.org/ufo-flux1s-flux-upscaled WAYYY better than this one. It also read/write EXIF prompts to images and
is the only other gen on perchance.org that does so, this one also being mine.

You can also import all the images (unzipped) into
https://perchance.org/ufo-gif-maker to create a VERY good quality gif with loads of options.

For more generators I made feel free to visit
https://perchance.org/-u-f-o- my public gens hub. Cheers!
